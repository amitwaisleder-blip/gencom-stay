# Gencom Stay — property photos

Drop a hotel photo here named exactly `<property-id>.jpg` and it appears
automatically on that property's card and detail page. If a file is missing,
the elegant monogram tile shows instead — so it's always safe to add them one
at a time.

- Format: **JPG**, named `<id>.jpg` (lowercase, exactly as listed below)
- Recommended: landscape, ~1200×720px or larger (cards crop to a 5:3 ratio)
- Source: Gencom's own marketing/property photography (rights-cleared)
